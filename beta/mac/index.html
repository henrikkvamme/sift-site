Download for Mac ↓

Signed with Developer ID and notarized by Apple. Windows or Linux instructions.

  1. 1

    Run Sift Beta Setup.

    Open the downloaded ZIP, then open Sift Beta Setup and choose Install.

    Setup keeps Sift in Application Support, safely outside Downloads, and copies its folder path for you.

  2. 2

    Open your extensions.

    Paste this address into a new Chrome tab.

  3. 3

    Turn on Developer mode.

    You’ll find the toggle in the top right.

  4. 4

    Add Sift.

    Copy this folder path. Select Load unpacked, press ⌘⇧G, paste it and select the folder.

    Keep Developer mode on. You only need these steps once per browser profile.

Ready when you are.

Open YouTube, or refresh it if it’s already open.

Open YouTube ↗ in a new tab

Future updates: open Sift Settings and choose Update Sift and refresh. Your preferences and local data stay, and videos remain paused at their position.

Already using Sift?

Moving an unpacked beta

Run Setup and load the new folder without removing Sift from Chrome first. Removing the extension can erase its local data. Then refresh your YouTube tabs.

Already installed with Setup

Update from Sift Settings. You do not need to download Setup again for ordinary updates.

Using the Chrome Web Store version

Chrome updates that version automatically. If you want the beta, turn off the Store version before enabling it.

Need to repair the installation?

Run Sift Beta Setup from your home Applications folder, or download the latest installer above.

Using more than one profile?

After updating one profile, open Sift Settings in the others to refresh them to the installed version.
