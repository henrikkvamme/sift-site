Install Sift
  1. 1

    Unzip the download.

    Open sift-beta.zip and extract its contents.

    Keep the unzipped folder. Chrome will use it.

    ZIP
  2. 2

    Open your extensions.

    Paste this address into a new Chrome tab.

  3. 3

    Turn on Developer mode.

    You’ll find the toggle in the top right.

  4. 4

    Add Sift.

    Select Load unpacked, then choose the folder you just unzipped.

Need a hand?

The download didn’t start.

Download the ZIP again. Open it from your browser’s Downloads.

Chrome can’t find the extension.

Select the unzipped folder containing manifest.json, not the ZIP or its parent folder.

Already have Sift?

Turn off the old Store version before enabling this beta. To update an unpacked beta, replace the files in its existing folder and select Reload on Sift’s card. Then refresh YouTube.

Want to activate Pro?

Open Sift’s account menu on YouTube and sign in with Google. Your early-access offer starts when you activate it.
